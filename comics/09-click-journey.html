09 · 终幕：一次点击的完整旅程 ​

九幕演完，到了串场谢幕。这一章没有新知识——只有全链路：当用户点下一个按钮，前面认识的每一位演员如何在一帧之内接力跑完一圈。

一、第 1~3 站：事件进山洞 ​

手指落下的瞬间，系统触摸事件先在原生 UI 线程被捕获。06 章的触控管家 Pressability 在 JS 侧等着（[Pressability.js:L371](file:///Users/yangzhijie/Desktop/practice_projects/claude-code-test/_rn-source/react-native-0.87.1/Libraries/Pressability/Pressability.js#L371) 起的默认导出类），但事件并不直接去 JS——它先进 C++ 的事件管线，由 [EventDispatcher.cpp:L26](file:///Users/yangzhijie/Desktop/practice_projects/claude-code-test/_rn-source/react-native-0.87.1/ReactCommon/react/renderer/core/EventDispatcher.cpp#L26) 的 dispatchEvent 按 target 视图把事件与影子树里的 tag 对上号，再经 JSI 直呼 ReactFabric（该模块在 [ReactFabric.js:L30](file:///Users/yangzhijie/Desktop/practice_projects/claude-code-test/_rn-source/react-native-0.87.1/Libraries/Renderer/shims/ReactFabric.js#L30) 通过 registerCallableModule 登记为"原生可回调"）。

事件为什么过 C++ 而不过旧 Bridge？因为新架构里 C++ 是中立的裁判：它同时认识原生视图和 React 树，谁都不用绕路。这就是"同步可达"的物理基础。

二、第 4~5 站：React 接单，Fabric 排产 ​

JS 线程上，React 调度器处理你 setState 里的更新（并发模式下还能被打断、让位给更紧急的事件）。算完新树，交稿给 Fabric：UIManager.completeSurface（[UIManager.cpp:L191](file:///Users/yangzhijie/Desktop/practice_projects/claude-code-test/_rn-source/react-native-0.87.1/ReactCommon/react/renderer/uimanager/UIManager.cpp#L191)，05 章第二站）。

影子树 commit 在 [ShadowTree.cpp:L303](file:///Users/yangzhijie/Desktop/practice_projects/claude-code-test/_rn-source/react-native-0.87.1/ReactCommon/react/renderer/mounting/ShadowTree.cpp#L303)：若同时有别的更新在跑，带版本重试；成功后 Yoga 就地布局。

三、第 6~7 站：拆单与上屏 ​

Differentiator 在 [Differentiator.cpp:L122](file:///Users/yangzhijie/Desktop/practice_projects/claude-code-test/_rn-source/react-native-0.87.1/ReactCommon/react/renderer/mounting/Differentiator.cpp#L122) 的 calculateShadowViewMutations 拆出五种指令（CREATE / INSERT / UPDATE / REMOVE / DELETE），MountingCoordinator 基于 revision 推进。指令回到原生 UI 线程：Android 的 FabricUIManager、iOS 的 RCTViewComponentView 逐条执行——按钮高亮、文字变化，屏幕上的像素更新完毕。

四、第 8 站：回声 ​

commit 收尾回发 layout events。如果你的代码里有 onLayout，它会晚一拍回到 JS——这就是"onLayout 里改状态必然多一帧"的原理。同理，Text 的测量回包也是这条回声路径。

三者像三班倒的工厂：上一棒不堵下一棒。当动画卡顿，先问是哪一棒堵了——这正是 09 章给你的调试坐标系。

六、FAQ ​

Q1：点击到上屏一共跨几次语言边界？ 事件进 JS 一次（native→C++→JS），渲染回 native 一次（JS→C++→native），共两次"大跨界"。比旧 Bridge 的 JSON 序列化轻一个数量级。

Q2：为什么交互时 setState 不 Immediately 生效？ React 需要一个批处理窗口来合并同一帧内的多次更新；新架构把窗口压缩到极短，但"合批"本身是正确性的来源。

Q3：如何实测这一圈多长？ Dev Menu → "Show Perf Monitor"，或用 RN DevTools 的 Timeline；再用 InteractionManager 在业务侧打点对照。
