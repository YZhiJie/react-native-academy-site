教程 06 · 调试：RN DevTools / Hermes / 常见报错急救 ​

目标：建立"三层调试"体系——JS 调试器、运行时监控、报错急救手册。目标是 90% 的问题 10 分钟内定位。

一、RN DevTools（0.87 官方首选） ​

React Native DevTools 是 0.87 内置的统一调试前端（基于 Chrome DevTools 协议，直连 Hermes）：

- 模拟器里 Cmd+D（iOS）/ Cmd+M 或摇一摇（Android）→ Open React Native DevTools

text

1. 进入页面 A，拍快照 s1

三、React 19 专属：onCaughtError 全局兜底 ​

tsx
// index.js —— React 19 新错误处理钩子（0.87 专属可用）
import { AppRegistry } from 'react-native';
import App from './App';
import { name as appName } from './app.json';

AppRegistry.registerComponent(appName, () => App, {
  // 组件树内错误边界捕获的错误（上报到监控平台的位置）
  onCaughtError: error => reportToSentry(error),
  // 未被任何 Error Boundary 捕获的错误（直接崩 App 的）
  onUncaughtError: error => reportFatal(error),
});

配合页面级 Error Boundary + resetKey 恢复机制：

tsx
class ScreenBoundary extends React.Component<
  { children: React.ReactNode },
  { error: Error | null }
> {
  state = { error: null as Error | null };

  static getDerivedStateFromError(error: Error) {
    return { error }; // 渲染期错误 → 状态
  }

  componentDidCatch(error: Error) {
    // 上报（含组件栈）
    console.error('[Boundary]', error);
  }

  render() {
    if (this.state.error) {
      return (
        <View style=&#123;&#123; flex: 1, justifyContent: 'center' &#125;&#125;>
          <Text>页面开小差了</Text>
          {/* 重试：清空错误状态，React 重新渲染子树 */}
          <Button title="重试" onPress={() => this.setState({ error: null })} />
        </View>
      );
    }
    return this.props.children;
  }
}

五、日常调试流（推荐节奏） ​

text
1. 改代码 → Metro 热载（秒级验证 UI）
2. 出问题 → RN DevTools：Console 报错栈 → Sources 断点跟
3. 网络类 → Network 面板看请求/响应
4. 卡顿类 → Perf Monitor 看帧率 → 定位 JS/UI/C++ 哪一侧
5. 怪异类 → 核弹选项：清缓存重启（--reset-cache）→ 删 node_modules 重装
6. 原生类 → Xcode Console / Android Logcat（npx react-native log-ios / log-android）

FAQ ​

Q1：console.log 太多拖慢 App 吗？ Debug 构建会（日志过 Hermes bridge），Release 构建里 console 调用默认被剥离。提交前用 eslint 规则 no-console 兜底。

Q2：能在真机上远程调试吗？ 能。真机与电脑同 Wi-Fi（或 USB + adb reverse），DevTools 照常连。生产包（Release）不可调试属正常安全设计。

Q3：如何看 Release 包的错误？ 接 Sentry/Crashlytics 类崩溃收集，配合 3.1 的 onCaughtError/onUncaughtError 上报；本地用 Release 构建 + Xcode/Logcat 复现。
