组件 01 · Bouncy Checkbox 弹性复选框 ​

react-native-bouncy-checkbox@4.1.4 —— 带弹跳回弹动画的复选框，把"机械的勾选"变成"有手感的确认"。 原理预告：它的"弹性"正是漫画 06 章 Animated 管家的 spring 动画。

一、安装与配置 ​

bash
npm i react-native-bouncy-checkbox@4.1.4

# 依赖 reanimated（0.87 需 4.x）与 worklets 插件
npm i react-native-reanimated@4.7.0 react-native-worklets@0.13.0

二、基础用法 ​

tsx
import React, { useState } from 'react';
import BouncyCheckbox from 'react-native-bouncy-checkbox';
import { View, Text, StyleSheet } from 'react-native';

export default function SimpleCheck() {
  const [checked, setChecked] = useState(false);

  return (
    <View style={styles.row}>
      <BouncyCheckbox
        size={24}                                  // 勾选框尺寸（正方形边长）
        isChecked={checked}
        text="同意用户协议"
        textStyle={styles.text}                    // 文字样式（选中时默认加删除线！）
        fillColor="#6BCB77"                        // 选中后的填充色
        unfillColor="#FFF"                         // 未选中时的底色
        iconStyle=&#123;&#123; borderRadius: 6 &#125;&#125;            // 图标框样式
        onPress={(isChecked: boolean) => setChecked(isChecked)}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  row: { padding: 16 },
  text: {
    fontSize: 16,
    // 嫌"选中划掉文字"太故意？关掉它：
    textDecorationLine: 'none',
  },
});

三、受控/非受控与状态管理 ​

tsx
/**
 * 两种使用姿势：
 * ① 非受控：只传 onPress，组件内部自管状态（适合独立表单项）
 * ② 受控：传 isChecked + onPress，状态由父级管理（适合表单提交/联动）
 */

// 受控 + 与 Zustand 联动（教程 05 章的 store）
import { useSettingsStore } from '../stores/settingsStore';

export default function StoreCheckbox() {
  // selector 只取一个字段（原始值），保证订阅精准
  const darkMode = useSettingsStore(s => s.darkMode);
  const toggleDark = useSettingsStore(s => s.toggleDark);

  return (
    <BouncyCheckbox
      isChecked={darkMode}
      text="深色模式"
      fillColor="#9B5DE5"
      onPress={toggleDark} // 把"勾选"这个语义动作映射到 store action
    />
  );
}

四、高级：禁用/半选/自定义图标 ​

tsx
import BouncyCheckbox from 'react-native-bouncy-checkbox';
import { Image } from 'react-native';

export function Advanced() {
  return (
    <>
      {/* 1. 禁用态：交互关闭但保留视觉 */}
      <BouncyCheckbox text="已下架商品" disableText disableBuiltInState isChecked={false} />

      {/* 2. 自定义勾选图标：换成任意组件（默认是勾） */}
      <BouncyCheckbox
        isChecked={true}
        IconComponent={
          // 自定义图标组件：勾选状态下渲染这个
          <Image source={require('../assets/star.png')} style=&#123;&#123; width: 18, height: 18 &#125;&#125; />
        }
        fillColor="#FF9F45"
      />

      {/* 3. 触发式取值：不传 text 时作为纯开关按钮使用 */}
      <BouncyCheckbox
        isChecked={false}
        size={32}
        fillColor="#61DAFB"
        onPress={checked => console.log('纯图标开关：', checked)}
      />
    </>
  );
}

五、自定义技巧 ​

  1. 弹性手感调参：动画由 reanimated spring 驱动，视觉上通过 size、fillColor、iconStyle 组合即可获得截然不同的气质（大圆 + 粗边框 = 亲和风；小方 + 深色 = 专业风）；
  2. 文字任意化：text 传 ReactNode 可放富文本（如带链接的协议名）：
tsx
<BouncyCheckbox
  text={(
    <Text>
      同意<Text style=&#123;&#123; color: '#61DAFB' &#125;&#125;>《用户协议》</Text>与
      <Text style=&#123;&#123; color: '#61DAFB' &#125;&#125;>《隐私政策》</Text>
    </Text>
  ) as any} // text 类型是 string | ReactNode，TS 严格模式下断言一次
  textStyle=&#123;&#123; fontSize: 14 &#125;&#125;
/>

六、性能注意事项 ​

  • 列表里的复选框（多选删除场景）务必受控 + 行级 memo（漫画 06/09 章：状态变化只应重渲染"那一行"）；
  • 选中状态放 store 时 selector 取布尔原始值，避免返回对象；
  • 不要在 onPress 里做重计算（如全列表过滤），派生数据用 useMemo。

FAQ ​

Q1：勾选后文字被划掉了？ 默认行为（textDecorationLine 删除线）。在 textStyle 里设 textDecorationLine: 'none' 关闭。

Q2：装完没动画？ 三查：babel plugin 是否在最后、是否 --reset-cache 重启、是否用了 0.87 兼容的 reanimated 4.7.0 + worklets 0.13.0。

Q3：能做"半选"态吗？ 库本身无 indeterminate；用 fillColor="#999" + 自定义 IconComponent 模拟即可。
