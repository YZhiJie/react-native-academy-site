组件 03 · Gifted Chat 智能聊天 ​

react-native-gifted-chat@3.4.0 —— 消息气泡、输入框、头像、时间分组、发送中状态，一个组件全包。 内部由 FlatList 驱动（倒置列表 + 虚拟化），消息管理正是漫画 06 章列表管家的应用。

二、基础用法：能收能发的聊天室 ​

tsx
// screens/ChatRoom.tsx
import React, { useCallback, useState, useMemo } from 'react';
import { GiftedChat, IMessage } from 'react-native-gifted-chat';

export default function ChatRoom() {
  const [messages, setMessages] = useState<IMessage[]>([
    {
      _id: 1,                       // 全局唯一（数字或字符串）
      text: '你好！这是机器人欢迎消息 👋',
      createdAt: new Date(),
      user: { _id: 2, name: '小助手', avatar: 'https://i.pravatar.cc/100?u=b' },
    },
  ]);

  // 当前登录用户 —— 决定气泡左右与颜色（_id: 1 是"我"）
  const me = useMemo(() => ({ _id: 1, name: '我', avatar: 'https://i.pravatar.cc/100?u=a' }), []);

  // 发送逻辑：GiftedChat 的 append 帮你把新消息"接"到列表头
  const onSend = useCallback((newMsgs: IMessage[] = []) => {
    setMessages(prev => GiftedChat.append(prev, newMsgs));
    // 真实业务：此处调 IM SDK / WebSocket 发送（教程 05 章 store 模式收状态）
  }, []);

  return (
    // GiftedChat 自带键盘避让（KeyboardAvoidingView 内置），无需自己包
    <GiftedChat
      messages={messages}
      onSend={onSend}
      user={me}                            // 必传：当前用户
      placeholder="说点什么…"
      alwaysShowSend                       // 输入框为空也显示发送按钮
      showUserAvatar                       // 对方消息显示头像
      renderUsernameOnMessage              // 群聊显示昵称
    />
  );
}

三、高级：发送中/失败状态与历史加载 ​

tsx
import { GiftedChat, InputToolbarProps, SendProps } from 'react-native-gifted-chat';

// ① 发送中状态：pending 标记 + 自定义发送按钮
function ChatWithStatus() {
  const [messages, setMessages] = useState<IMessage[]>([]);
  const [sending, setSending] = useState(false);

  const onSend = useCallback(async (msgs: IMessage[] = []) => {
    const withPending = msgs.map(m => ({
      ...m,
      pending: true,      // 库内置标记：气泡半透明+转圈
      sent: false,
    }));
    setMessages(prev => GiftedChat.append(prev, withPending));
    try {
      await sendToServer(msgs);
      // 成功：把 pending/sent 标记翻转
      setMessages(prev =>
        prev.map(m =>
          withPending.some(w => w._id === m._id) ? { ...m, pending: false, sent: true } : m,
        ),
      );
    } catch {
      // 失败：标记失败，点击可重发
      setMessages(prev => prev.map(m => (m.pending ? { ...m, pending: false } : m)));
    }
  }, []);

  return (
    <GiftedChat
      messages={messages}
      onSend={onSend}
      user=&#123;&#123; _id: 1 &#125;&#125;
      // ② 自定义发送按钮（换图标/加禁用态）
      renderSend={props => <Send {...props} containerStyle=&#123;&#123; marginBottom: 8 &#125;&#125; />}
      // ③ 加载历史（下拉翻旧消息）：loadEarlier 系列
      loadEarlier
      isLoadingEarlier={false}
      onLoadEarlier={() => fetchHistory().then(older => setMessages(p => GiftedChat.append(p, older)))}
    />
  );
}

六、性能注意事项 ​

  • 消息列表只存近千条、渲染窗口化：历史消息入库（教程 05 章持久化），列表只保留最近一屏的数据量级；
  • 消息对象不可变更新（永远 GiftedChat.append 或 map 拷贝），别原地改数组；
  • 头像用小尺寸图（72px 足够），每行头像解码都在 UI 线程。

FAQ ​

Q1：键盘弹起输入框被挡？ 确认用的是 GiftedChat 而非手动包 KeyboardAvoidingView（内置处理了双端差异）；Android 同时检查 android:windowSoftInputMode="adjustResize"。

Q2：新消息发出后列表没滚动到底？ 倒置列表的特性是"数据头即视觉底"，确认用了 GiftedChat.append；必要时配 inverted={false} 改成正向列表（放弃虚拟化优化前请三思）。

Q3：长按消息想加"撤回"？onLongPress={(ctx, msg) => showSheet(msg)}，配组件 02 的 Bottom Sheet 做操作菜单。
