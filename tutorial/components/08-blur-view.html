组件 08 · Blur View 模糊视图 ​

@react-native-community/blur@4.4.1 —— 对底层内容实时取样的半透明毛玻璃效果：遮罩、顶栏、弹窗的高级感来源。 0.87 冷知识：iOS 侧新目录 ReactApple 的 SwiftUI 容器已内置 blur/grayscale/saturation 等滤镜（漫画 08 章），轻量场景未来可替代三方库。

一、安装与配置 ​

bash
npm i @react-native-community/blur@4.4.1
cd ios && pod install && cd ..
1
2

注意：Android 侧效果依赖 experimentalBlurMethod（见下文），且双端渲染原理不同 —— iOS 用系统 UIVisualEffectView，Android 用 RenderEffect/RenderScript 模拟。务必真机验证。

二、基础用法：模糊浮层 ​

tsx
// screens/BlurDemo.tsx
import React from 'react';
import { View, Image, Text, StyleSheet } from 'react-native';
import { BlurView } from '@react-native-community/blur';

export default function BlurDemo() {
  return (
    <View style={styles.container}>
      {/* 底层内容：模糊视图会对它"取样" */}
      <Image
        source=&#123;&#123; uri: 'https://picsum.photos/800/1200' &#125;&#125;
        style={StyleSheet.absoluteFill}   // 铺满父容器
      />

      {/* 浮层卡片：绝对定位 + BlurView 填充 */}
      <View style={styles.card}>
        <BlurView
          style={StyleSheet.absoluteFill}   // 模糊层铺满卡片
          blurType="light"                  // light / dark / extraLight / regular
          blurAmount={20}                   // 模糊强度（iOS 上 10~25 手感最佳）
          // ↓ Android 专属：默认 'dimezisBlurView'（真机可用）
          experimentalBlurMethod="dimezisBlurView"
        />
        {/* 内容必须放在模糊层【之后】，否则也被模糊掉 */}
        <Text style={styles.cardText}>毛玻璃卡片上的清晰文字</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1 },
  card: {
    margin: 32, padding: 24,
    borderRadius: 16, overflow: 'hidden',  // 关键：裁剪出圆角，否则模糊层是方的
    backgroundColor: 'rgba(255,255,255,0.2)',
  },
  cardText: { fontSize: 18, color: '#2D2A32', textAlign: 'center' },
});

三、高级：全屏 Modal 模糊遮罩 ​

tsx
import { Modal, View, BlurView } from 'react-native';
import { Blurhash } from '@react-native-community/blur'; // 还可用 Blurhash 图片占位

function BlurredModal({ visible, onClose, children }) {
  return (
    <Modal visible={visible} transparent animationType="fade" onRequestClose={onClose}>
      {/* 模糊整层背景 */}
      <BlurView
        style={StyleSheet.absoluteFill}
        blurType="dark"          // 暗色毛玻璃（弹窗遮罩常用）
        blurAmount={16}
        experimentalBlurMethod="dimezisBlurView"
        reducedTransparencyFallbackColor="#2D2A32"  // 系统减弱透明度时的兜底色
      />
      {/* 点击空白关闭 */}
      <View style=&#123;&#123; flex: 1 &#125;&#125; onStartShouldSetResponder={onClose} />
      {children}
    </Modal>
  );
}

四、Blurhash：图片加载的"预览模糊" ​

tsx
import { Blurhash } from '@react-native-community/blur';

// 远图未加载完成时，先渲染几字符的 Blurhash（体积小、解码快、视觉近似）
function SmartImage({ hash, uri }) {
  const [loaded, setLoaded] = useState(false);
  return (
    <View style=&#123;&#123; width: '100%', aspectRatio: 1.5 &#125;&#125;>
      {!loaded && (
        <Blurhash
          blurhash={hash}          // 服务端下发的一串 hash 字符串
          style={StyleSheet.absoluteFill}
        />
      )}
      <Image
        source=&#123;&#123; uri &#125;&#125;
        style={StyleSheet.absoluteFill}
        onLoad={() => setLoaded(true)}   // 加载完成后切真图
      />
    </View>
  );
}

五、自定义技巧 ​

  • 振动提示条样式：blurType 组合 blurAmount 调风格（light+10 = 清爽、dark+20 = 沉稳）；
  • 动态模糊强度：blurAmount 受控，配合 reanimated 共享值做"聚焦过渡"（注意它不是 Animated API，需 reanimated 的 animate prop 桥接）；
  • 性能降级方案：低端 Android 机提供 reducedTransparencyFallbackColor + 检测系统"减少透明度"设置。

六、性能注意事项 ​

  • 实时模糊是 GPU 高开销操作：同一屏幕最多 1~2 个 BlurView；列表行内禁用（改用半透明纯色 rgba 或预烘焙模糊图）；
  • Android 上 dimezisBlurView 每帧重采样，嵌套滚动时帧率压力明显 —— 弹窗/浮层用，滚动区不用；
  • 模糊区域越大越贵：能用小卡片模糊就别全屏模糊。

七、常见用例 ​

用例配置
顶栏毛玻璃BlurView + blurType light + 固定高度
弹窗遮罩Modal + dark 全屏模糊
图片占位Blurhash 组件
播放器控制栏底部浮层 + dark + overflow hidden 圆角

FAQ ​

Q1：Android 上没效果/白块？experimentalBlurMethod="dimezisBlurView" 没加，或模拟器 GPU 不支持 —— 真机验证。

Q2：模糊层把文字也糊了？ 内容没叠在 BlurView 之后，或内容自己也放进 BlurView 里了。结构必须是：容器(overflow hidden) > BlurView(absoluteFill) > 内容。

Q3：列表滚动时模糊撕裂？ 实时取样与滚动同步的固有代价。列表内改用静态方案：半透明背景 + 边框阴影，或预渲染模糊图。
