组件 07 · Pager View 页面视图 ​

react-native-pager-view@9.0.5 —— 原生驱动的横滑翻页容器：抖音式上下滑、引导页、Top Tab 联动的底座。 它的核心是原生手势 + 原生滚动容器，翻页不经过 JS 线程 —— 天生 60fps。

一、安装与配置 ​

bash
npm i react-native-pager-view@9.0.5
cd ios && pod install && cd ..
1
2

纯原生组件，无 JS 动画依赖；与 gesture-handler/reanimated 无强耦合，可独立使用。

二、基础用法：三页横滑 ​

tsx
// screens/PagerDemo.tsx
import React, { useRef, useState } from 'react';
import PagerView from 'react-native-pager-view';
import { View, Text, StyleSheet } from 'react-native';

export default function PagerDemo() {
  // ref：程序化翻页
  const pagerRef = useRef<PagerView>(null);
  const [page, setPage] = useState(0);

  return (
    <PagerView
      ref={pagerRef}
      style={styles.pager}
      initialPage={0}                    // 初始页
      onPageSelected={e => setPage(e.nativeEvent.position)}  // 页面稳定后回调（驱动指示器）
      onPageScrollStateChanged={e =>
        console.log('滑动状态：', e.nativeEvent.pageScrollState) // idle/dragging/settling
      }
    >
      <View key="0" style={[styles.page, { backgroundColor: '#61DAFB' }]}>
        <Text style={styles.txt}>第一页</Text>
      </View>
      <View key="1" style={[styles.page, { backgroundColor: '#FFD93D' }]}>
        <Text style={styles.txt}>第二页</Text>
      </View>
      <View key="2" style={[styles.page, { backgroundColor: '#6BCB77' }]}>
        <Text onPress={() => pagerRef.current?.setPage(0)}>回第一页（程序化翻页）</Text>
      </View>
    </PagerView>
  );
}

const styles = StyleSheet.create({
  pager: { flex: 1 },
  page: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  txt: { fontSize: 22, fontWeight: '700' },
});

三、高级：页面指示器 + Top Tab 联动 ​

tsx
import { View, Text, Pressable, StyleSheet } from 'react-native';
import PagerView from 'react-native-pager-view';

const TABS = ['推荐', '关注', '热榜'];

export default function TabPager() {
  const pagerRef = useRef<PagerView>(null);
  const [page, setPage] = useState(0);

  return (
    <View style=&#123;&#123; flex: 1 &#125;&#125;>
      {/* 顶部 Tab：点击 → 程序化翻页 */}
      <View style={styles.tabs}>
        {TABS.map((tab, i) => (
          <Pressable
            key={tab}
            onPress={() => {
              pagerRef.current?.setPage(i);   // 无动画跳页
              // pagerRef.current?.setPageWithoutAnimation(i) 也有，适合恢复场景
            &#125;&#125;
          >
            <Text style={[styles.tab, i === page && styles.tabActive]}>{tab}</Text>
          </Pressable>
        ))}
      </View>

      <PagerView
        ref={pagerRef}
        style=&#123;&#123; flex: 1 &#125;&#125;
        initialPage={0}
        onPageSelected={e => setPage(e.nativeEvent.position)}
        // 手势调优：
        swipeVelocityThreshold={1800}   // 翻页速度阈值（越大越"钝"）
        overdrag={false}                // 禁止边缘过拽回弹（iOS）
        layoutDirection="ltr"
      >
        {TABS.map((tab, i) => (
          <View key={String(i)} style=&#123;&#123; flex: 1 &#125;&#125;>
            <FeedList tab={tab} />       {/* 每页一个列表（组件 10 的 FlashList） */}
          </View>
        ))}
      </PagerView>

      {/* 页点指示器 */}
      <View style={styles.dots}>
        {TABS.map((_, i) => (
          <View key={i} style={[styles.dot, i === page && styles.dotActive]} />
        ))}
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  tabs: { flexDirection: 'row', justifyContent: 'center', gap: 24, paddingVertical: 12 },
  tab: { fontSize: 16, color: '#999' },
  tabActive: { color: '#FF6B9D', fontWeight: '700' },
  dots: { flexDirection: 'row', justifyContent: 'center', gap: 6, paddingVertical: 10 },
  dot: { width: 6, height: 6, borderRadius: 3, backgroundColor: '#CCC' },
  dotActive: { width: 18, backgroundColor: '#FF6B9D' },
});

四、自定义技巧 ​

  1. 垂直翻页（短视频流）：orientation="vertical" —— 每页全屏视频，offscreenPageLimit={1} 只预加载相邻 1 页；
  2. 过渡动画：onPageScroll={e => e.nativeEvent.offset} 拿到 0~1 的翻页进度，配合 reanimated 做视差/缩放效果；
  3. 滚动锁定：scrollEnabled={false} 纯程序化翻页（向导/问卷场景）。

五、性能注意事项 ​

  • 每页都是常驻原生视图（不像 FlatList 会回收）—— 页数控制在个位数；多页内容用 offscreenPageLimit 控制预渲染范围；
  • 页内放列表时给列表开启懒加载（initialNumToRender 收紧），避免首翻页卡顿；
  • onPageScroll 是高频回调（逐帧），里面只做轻量的共享值赋值（reanimated useSharedValue），别 setState。

六、常见用例 ​

用例配置
新手引导页scrollEnabled false + 按钮翻页
短视频流orientation vertical + offscreenPageLimit 1
Top Tab 内容联动Tab 点击 setPage + onPageSelected 回写状态
日历周/月视图切换组件 09 的容器外壳

FAQ ​

Q1：滑动手势和内部 ScrollView 打架？ 正常情况下 PagerView 与子列表能协商；冲突时给内部列表加 nestedScrollEnabled，并把 PagerView 的 swipeVelocityThreshold 调大。

Q2：翻页时页面内容闪一下？ 页面组件被重新挂载导致。给每页内容加稳定 key + memo；确认没在 onPageSelected 里做 setState 引发整树重渲染（只 setPage 给指示器用）。

Q3：能懒加载页面吗？ 原生侧无懒加载选项（视图常驻），JS 侧自行控制：页面状态 page !== i 时渲染占位（配合组件 06 骨架）。
