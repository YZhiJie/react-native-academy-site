组件 04 · Charts 图表 ​

react-native-gifted-charts@1.4.78 —— 折线/柱状/饼图/面积图一套搞定，纯 SVG+JS 实现（无原生代码，装完即用）。 它把"数据 → 图形"的过程拆成纯声明式配置，和漫画 05 章 Fabric 的"指令化渲染"异曲同工。

一、安装与配置 ​

bash
npm i react-native-gifted-charts@1.4.78
# 依赖 react-native-linear-gradient（面积图/柱状渐变需要）
npm i react-native-linear-gradient
cd ios && pod install && cd ..

二、基础：柱状图与折线图 ​

tsx
// screens/ChartDemo.tsx
import React from 'react';
import { View, ScrollView, StyleSheet } from 'react-native';
import { BarChart, LineChart, PieChart } from 'react-native-gifted-charts';

const weeklyData = [
  { value: 120, label: '一' },
  { value: 90, label: '二', frontColor: '#FF6B9D' }, // 单项改色（高亮峰值）
  { value: 150, label: '三' },
  { value: 60, label: '四' },
  { value: 180, label: '五' },
  { value: 40, label: '六' },
  { value: 70, label: '日' },
];

export default function ChartDemo() {
  return (
    <ScrollView contentContainerStyle={styles.wrap}>
      {/* ① 柱状图 */}
      <BarChart
        data={weeklyData}
        barWidth={22}
        barBorderRadius={6}
        frontColor="#61DAFB"          // 默认柱色
        noOfSections={4}              // 纵轴分 4 段
        isAnimated                    // 进场生长动画（JS 驱动）
        hideRules                     // 隐藏横向网格线
        xAxisLabelTextStyle=&#123;&#123; color: '#666' &#125;&#125;
      />

      {/* ② 折线图 */}
      <LineChart
        data={weeklyData}
        curved                        // 曲线平滑
        thickness={3}
        color="#9B5DE5"
        dataPointsColor="#9B5DE5"     // 数据点颜色
        startFillColor="rgba(155,93,229,0.4)"  // 面积渐变起点
        endFillColor="rgba(155,93,229,0.01)"   // 面积渐变终点
        startOpacity={0.4}
        endOpacity={0.01}
        isAnimated
      />

      {/* ③ 饼图 */}
      <PieChart
        data={[
          { value: 40, color: '#61DAFB', label: '学习' },
          { value: 30, color: '#FFD93D', label: '工作' },
          { value: 20, color: '#6BCB77', label: '运动' },
          { value: 10, color: '#FF6B9D', label: '娱乐' },
        ]}
        donut                         // 环形（甜甜圈）模式
        showText                      // 扇区上显示数值
        textColor="#2D2A32"
        radius={90}
        innerRadius={60}              // donut 模式的内孔半径
      />
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  wrap: { padding: 16, gap: 40, backgroundColor: '#FFF' },
});

三、高级：点击交互与动态数据 ​

tsx
import React, { useState, useCallback } from 'react';
import { BarChart } from 'react-native-gifted-charts';

function InteractiveBar() {
  const [activeIndex, setActiveIndex] = useState<number | null>(null);

  // 数据来自接口（教程 05 章的 store 模式）；这里简化为本地
  const data = useMemo(
    () =>
      weeklyData.map((d, i) => ({
        ...d,
        // 被选中的柱子高亮 + 加粗
        frontColor: i === activeIndex ? '#FF9F45' : '#61DAFB',
        onPress: () => setActiveIndex(i),     // 每根柱子可点击
        showValue: i === activeIndex,         // 选中才显示数值标签
      })),
    [activeIndex],
  );

  return <BarChart data={data} barWidth={22} isAnimated />;
}

// 程序化更新：模拟实时推送（WebSocket 场景，教程里聊天室同款链路）
function LiveLine() {
  const [points, setPoints] = useState([{ value: 20 }]);

  useEffect(() => {
    const timer = setInterval(() => {
      // 不可变更新 + 滑动窗口：只保留最近 20 个点
      setPoints(prev => [...prev.slice(-19), { value: 20 + Math.random() * 60 }]);
    }, 1000);
    return () => clearInterval(timer); // 泄漏防护（教程 06 章）
  }, []);

  return <LineChart data={points} curved thickness={2} color="#6BCB77" isAnimated />;
}

四、自定义技巧 ​

  1. 空态兜底：data.length === 0 时渲染占位图（配合组件 06 骨架屏是黄金搭档）；
  2. 纵轴文案：formatYLabel={(v: string) => ${v}k}；
  3. 组合图：<BarChart ... /> 上叠 LineChart（ xAxisLength 对齐），或用 stackedBars 做堆叠柱；
  4. 滚动大图：数据点多时给 scrollToEnd/scrollAnimation + 外层 ScrollView horizontal（库内置横向滚动支持：scrollable）。

五、性能注意事项 ​

  • 图表是纯 JS/SVG 渲染，数据点数百以上时避免 isAnimated（动画逐帧重算路径）；
  • 实时图表用滑动窗口截断数据（上面 LiveLine 的 slice 技巧），别无限追加；
  • 图表放在列表行里时，行必须 memo —— 图形组件重渲染成本远高于普通文本。

六、常见用例 ​

用例图型 + 配置
仪表盘周报BarChart + 点击高亮
心率/温度实时曲线LineChart curved + 滑动窗口
时间分配环图PieChart donut + showText
收支对比stackedBars 或双 frontColor 柱

FAQ ​

Q1：图表太宽被截断？ 数据点多时加 scrollable 属性（库内置横向滚动），或 width 显式给容器宽并 initialSpacing 调边距。

Q2：值都是 0 时图显示怪异？ 给 maxValue={1} 之类的下限，或空态分支直接渲染占位。

Q3：数字标签被柱子盖住？showValuesAsTopText 或 barMarginBottom 微调；饼图用 showTextBackground 给数字加底衬。
