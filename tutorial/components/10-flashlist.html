组件 10 · FlashList 高性能列表 ​

@shopify/flash-list@2.3.2 —— FlatList 的直接替代品：回收复用原生视图、单元格独立测量、内存占用与滚动性能全面领先。 这是组件篇收官：它把漫画 06 章"窗口化"思想做到了原生视图层。

一、安装与配置 ​

bash
npm i @shopify/flash-list@2.3.2
cd ios && pod install && cd ..

2

2.x 起内置 CellContainer 自动处理嵌套测量；对 RN 0.87 完全兼容，无额外原生配置。

tsx

<FlashList

  keyExtractor={item => item.id}
  renderItem={renderItem}

/>

三、基础用法：万条数据流畅滚动 ​

tsx
// screens/FeedList.tsx
import React, { useCallback, memo } from 'react';
import { FlashList, ListRenderItemInfo } from '@shopify/flash-list';
import { View, Text, Image, StyleSheet } from 'react-native';

type Video = { id: string; title: string; cover: string; likes: number };

// ① 行组件 memo：数据不变就不重渲染（配合 ② 的 useCallback）
const Row = memo(function Row({ item }: { item: Video }) {
  return (
    <View style={styles.row}>
      <Image source=&#123;&#123; uri: item.cover &#125;&#125; style={styles.cover} />
      <View style=&#123;&#123; flex: 1 &#125;&#125;>
        <Text numberOfLines={2} style={styles.title}>{item.title}</Text>
        <Text style={styles.likes}>❤ {item.likes}</Text>
      </View>
    </View>
  );
});

export default function FeedList({ data }: { data: Video[] }) {
  // ② renderItem 用 useCallback 固定引用，避免列表整体重渲染
  const renderItem = useCallback(
    ({ item }: ListRenderItemInfo<Video>) => <Row item={item} />,
    [],
  );

  return (
    <FlashList
      data={data}
      keyExtractor={item => item.id}
      renderItem={renderItem}
      estimatedItemSize={92}              // 行高估值（样式定死后是常数）
      onEndReachedThreshold={0.3}
      onEndReached={loadMore}             // 触底加载更多
      // ③ 空列表分隔线：与 FlatList 不同，FlashList 推荐 ItemSeparator
      ItemSeparatorComponent={() => <View style=&#123;&#123; height: 1, backgroundColor: '#EEE' &#125;&#125; />}
    />
  );
}

const styles = StyleSheet.create({
  row: { flexDirection: 'row', padding: 12, gap: 12, backgroundColor: '#FFF' },
  cover: { width: 120, height: 68, borderRadius: 8, backgroundColor: '#EEE' },
  title: { fontSize: 15, fontWeight: '600' },
  likes: { fontSize: 12, color: '#999', marginTop: 4 },
});

四、高级：瀑布流与分栏 ​

tsx
import { FlashList } from '@shopify/flash-list';

// 瀑布流（masonry）：2 列自适应高度
function MasonryFeed({ data }: { data: Card[] }) {
  return (
    <FlashList
      data={data}
      keyExtractor={item => item.id}
      renderItem={({ item }) => <CardItem item={item} />}
      masonry                            // 开启瀑布流模式
      numColumns={2}
      // 瀑布流里 estimatedItemSize 按"平均卡片高"给
      estimatedItemSize={180}
      contentContainerStyle=&#123;&#123; padding: 8 &#125;&#125;
    />
  );
}

// 双列网格（等高）：numColumns 即可，无需 masonry
function GridList({ data }: { data: Emoji[] }) {
  return (
    <FlashList
      data={data}
      numColumns={3}
      renderItem={({ item }) => <GridCell emoji={item} />}
      estimatedItemSize={56}
    />
  );
}

五、自定义技巧 ​

  1. 吸顶头部：stickyHeaderIndices={[0]}（第一个元素常驻顶部）配合 ListHeaderComponent；
  2. 倒置聊天列表：inverted + maintainVisibleContentPosition=&#123;&#123; disabled: false &#125;&#125; 让新消息不跳动（组件 03 GiftedChat 的底层同款思路）；
  3. 滚动定位：scrollToIndex({ index, viewPosition: 0 }) —— FlashList 无需 getItemLayout 也能准确定位（内部有测量缓存）。

六、性能注意事项（组件篇的性能总纲） ​

原则说明
estimatedItemSize 必给高度差异过大会引发滚动条跳动与空白帧
行级 memo + useCallback列表性能的"铁三角"（数据 memo → 回调 memo → 行 memo）
行内图片限尺寸固定宽高 + 正确的 resizeMode，避免异步测量抖动
避免行内高开销组件实时模糊（组件 08）、逐帧动画、未截断的长文本
分页而非全量onEndReached 增量加载，数据层滑动窗口（教程 05 章）

七、常见用例 ​

用例配置
社交信息流基础模式 + onEndReached 分页
图片瀑布流masonry + numColumns
聊天记录inverted + maintainVisibleContentPosition
多 Tab 列表（配组件 07）每页一个 FlashList + offscreenPageLimit=1

FAQ ​

Q1：比 FlatList 还卡？ 九成是 estimatedItemSize 离谱或行组件没 memo。先用 Perf Monitor 定位是 JS 渲染慢还是 UI 慢（教程 06 章）。

Q2：能替代组件 03 的 GiftedChat 吗？ 不建议直接替换 —— GiftedChat 的输入框/气泡生态是完整方案；但可给 GiftedChat 传自定义 messagesContainer 换 FlashList（进阶改造）。

Q3：下拉刷新支持吗？onRefresh + refreshing 与 FlatList 同名同义；配合组件 06 的骨架做首屏、RefreshControl 做翻页，体验闭环。
