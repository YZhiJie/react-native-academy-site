教程 03 · 核心概念：JSX、内置组件、StyleSheet 与平台差异 ​

目标：掌握 RN 与 Web React 的关键差异——没有 div/span，一切皆 RN 组件；样式是 JS 对象；布局是 Yoga Flexbox。

一、RN ≠ Web：三个心智转变 ​

  1. 没有 DOM：<div> 不存在，只有 <View>；文字必须包在 <Text> 里（裸文本直接报错）；
  2. 样式是 JS：不是 CSS 文件，是 StyleSheet.create 出来的对象；属性名驼峰化（backgroundColor 而非 background-color）；
  3. 布局是 Yoga：默认 flexDirection 是 column（Web 默认 row），宽度默认自适应父容器。

二、四大内置组件 ​

tsx
import React from 'react';
import { View, Text, Image, Pressable, StyleSheet } from 'react-native';

/**
 * 四大内置组件速览：
 * View      —— 容器/布局块，对应 Web 的 div
 * Text      —— 文本（层级嵌套可做富文本）
 * Image     —— 图片（必须显式给尺寸！）
 * Pressable —— 可按压容器（官方推荐，替代旧 TouchableOpacity 的多数场景）
 */
export default function BasicsDemo() {
  return (
    <View style={styles.card}>
      {/* Image 的 source：本地 require 或网络 uri，二选一 */}
      <Image
        source=&#123;&#123; uri: 'https://react.dev/favicon.ico' &#125;&#125;
        style={styles.avatar}
        resizeMode="cover"
      />
      <Text style={styles.title}>
        {/* Text 可嵌套：内层继承样式再做局部强调 */}
        <Text style={styles.highlight}>RN 0.87</Text> 基础四件套
      </Text>
      {/* Pressable 的 children 函数签名：拿到 pressed 状态做样式切换 */}
      <Pressable
        onPress={() => console.log('pressed!')}
        style={({ pressed }) => [styles.btn, pressed && styles.btnPressed]}
      >
        <Text style={styles.btnText}>点我</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  card: {
    flex: 1,                    // 占满父容器
    justifyContent: 'center',   // 主轴居中（默认主轴是 column）
    alignItems: 'center',       // 交叉轴居中
    gap: 12,                    // 子元素间距（Yoga 支持）
    backgroundColor: '#FFF',
  },
  avatar: { width: 48, height: 48, borderRadius: 24 }, // 图片必须给宽高
  title: { fontSize: 18 },
  highlight: { color: '#61DAFB', fontWeight: '700' },
  btn: { backgroundColor: '#2D2A32', paddingHorizontal: 24, paddingVertical: 10, borderRadius: 12 },
  btnPressed: { opacity: 0.6 }, // 按压态样式
  btnText: { color: '#FFF' },
});

三、StyleSheet 的正确用法 ​

tsx
// ① 用 StyleSheet.create 而不是内联对象字面量：
//    - 一次定义、跨渲染复用引用（配合 memo 减少重渲染）
//    - 类型检查与静态校验（写错属性名直接红线）
const styles = StyleSheet.create({ /* ... */ });

// ② 样式组合：数组后者覆盖前者，falsy 值自动跳过（条件样式利器）
<View style={[styles.base, isActive && styles.active]} />

// ③ 绝对定位：RN 的 position:absolute 相对父容器，且不参与布局流
<View style=&#123;&#123; position: 'absolute', top: 8, right: 8 &#125;&#125; />

性能小贴士：StyleSheet.create 的对象在 JS 侧是稳定引用。把样式提到组件外（或组件顶层 create），列表类组件每帧 diff 时可直接命中"样式未变"，省掉属性序列化开销。

四、列表初见：FlatList 与 ListEmptyComponent ​

tsx
import React, { useMemo } from 'react';
import { FlatList, Text, View } from 'react-native';

type Item = { id: string; name: string };

export default function ListDemo() {
  // useMemo 固定数据引用，避免每次渲染生成新数组导致列表重建
  const data = useMemo<Item[]>(
    () => Array.from({ length: 100 }, (_, i) => ({ id: String(i), name: `项目 ${i}` })),
    [],
  );

  return (
    <FlatList
      data={data}
      // keyExtractor：稳定的 key（别用 index）
      keyExtractor={item => item.id}
      renderItem={({ item }) => (
        <View style=&#123;&#123; padding: 16 &#125;&#125;>
          <Text>{item.name}</Text>
        </View>
      )}
      // 空态兜底：业务必备
      ListEmptyComponent={<Text style=&#123;&#123; textAlign: 'center' &#125;&#125;>暂无数据</Text>}
    />
  );
}

六、事件与状态的最小闭环 ​

tsx
import React, { useState } from 'react';
import { Pressable, Text, View } from 'react-native';

export default function Counter() {
  // useState：点击 → 状态更新 → React 调度 → Fabric 渲染新 UI
  const [count, setCount] = useState(0);

  return (
    <View style=&#123;&#123; flex: 1, justifyContent: 'center', alignItems: 'center', gap: 12 &#125;&#125;>
      <Text style=&#123;&#123; fontSize: 32 &#125;&#125;>{count}</Text>
      <Pressable onPress={() => setCount(c => c + 1)}>
        <Text>加一</Text>
      </Pressable>
    </View>
  );
}

FAQ ​

Q1：为什么 <Text> 里不能直接放 <View>？ Text 是特殊的内联渲染管线，混入块级容器会直接抛异常。需要图文混排用 <Image> + flex 行包裹，或用嵌套 Text。

Q2：像素单位是什么？ 无单位数字即"逻辑像素"（dp/pt），Yoga 自动处理与物理像素的换算，不要自己乘 devicePixelRatio。

Q3：Percent 布局支持吗？ 支持：width: '50%' 等百分比字符串可用于多数尺寸属性，但 fontSize 等不支持。
